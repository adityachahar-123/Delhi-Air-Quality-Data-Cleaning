# Delhi Air Quality – Data Acquisition and Cleaning

## Project
YuvaIntern Data Analytics Internship – Week 2

## Objective
To acquire, inspect, clean and prepare Delhi air-quality data for analysis.

## Dataset
Public Delhi air-quality data. Record the exact dataset source, download date and licence before analysis.

## Tools
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Cleaning Process
1. Inspect dataset structure and data types.
2. Identify missing values.
3. Remove duplicate records.
4. Check invalid and negative pollutant readings.
5. Investigate outliers using the IQR method.
6. Normalize selected numerical columns.
7. Encode categorical columns where required.
8. Export the cleaned dataset.

## Outputs
- Raw dataset (where redistribution is permitted)
- Cleaned dataset
- Data quality summary
- Before-and-after comparison

## Important
Actual results must be generated from the downloaded dataset. Do not treat example values as real measurements.
